# Zoomable Help File — Design

Date: 2026-07-17
Status: approved (brainstorming session)

## Purpose

Ship a help document with the app that is itself zoomable — so reading the manual doubles as trying the product. It describes how to use the app, how to set up every generation provider, and every feature. It opens with the macOS-standard Help shortcut, which is advertised in the empty-state footer, and it travels inside the DMG so every install has it.

## The template principle

A file inside the .app bundle is read-only in practice, and writing to it would break the app's code signature. But the help file must be safe to experiment on — including Remove zoom layers and re-generation, which write to disk. So the bundled file is a **template**: opening Help copies it to a writable location and opens the copy. Every press of the shortcut restores a pristine zoomable demo regardless of what the user did to the previous copy.

## Components

### 1. Content (`src-tauri/resources/help.md`)

Authored prose covering: what Semantic Zoom is; the three zoom levels and every way to move between them (scrubber, ⌘1/⌘2/⌘3, `[`/`]`, ⌘↑/⌘↓); opening files and live reload-on-edit; generating zoom layers with each provider kind — Ollama (local), custom local server, and remote providers including saving the API key and the fact that macOS will ask for Keychain access (denying it hides the Generate button); the status pill and the generation-history card; removing zoom layers (and that it is confirmed, reversible, and history-preserving); content scale (⌘=/⌘−/⌘0); the map sidebar.

The prose is finished first, then tagged with the embed-zoom-payload pipeline (segment → author layers → assemble → `validate.mjs` → compiled `verify_payload`). Both validators must pass before the file is done. No hand-authored IDs, ever (D6).

### 2. Rust command `install_help_file` (`src-tauri/src/commands/help.rs`)

`install_help_file(app) -> Result<String, String>`: resolves the bundled `resources/help.md` via Tauri's resource-dir API, copies it — always overwriting — to `<app-config-dir>/Semantic Zoom Help.md`, and returns that path. Copying uses the same atomic write-then-rename helper as `write_payload` so a half-copied help file can never be opened. Testable core function takes explicit source/target paths; the command wires the real dirs in. Registered in the invoke handler.

### 3. Frontend wiring (`main.ts`, `empty-state.ts`)

- `openHelp()`: `invoke('install_help_file')` → `openFile(returnedPath)`.
- **Help menu**: a `Help` submenu with "Semantic Zoom Help", accelerator `CmdOrCtrl+Shift+/` (rendered ⌘? on macOS).
- **DOM fallback**: a keydown handler for ⌘? in `installKeyboardShortcuts`, mirroring the existing ⌘↓/⌘↑ pattern — WebKit consumes key equivalents before the menu whenever it feels like it, and the menu accelerator alone was proven unreliable for exactly this class of shortcut (2026-07-09 investigation).
- **Footer hint**: `'⌘? — help'` appended to `FOOTER_HINTS` in `empty-state.ts`.

### 4. Bundling (`tauri.conf.json`)

`"resources": ["resources/help.md"]` under `bundle`. Tauri places it in `Contents/Resources/` of the .app; the DMG carries the .app, so the help file always ships.

## Error handling

- Resource missing (dev builds running outside a bundle): `install_help_file` falls back to the source-tree path when the resource lookup fails, so ⌘? works in `tauri dev` too. If neither exists, the error surfaces via the status pill's failure toast.
- Copy failure (disk full, permissions): command errors; toast; nothing opens.

## Testing

- Rust unit tests for the copy core: overwrites an existing (user-mutilated) target byte-for-byte from the template; creates parent dirs; propagates IO errors.
- TS test for the footer hint presence in `empty-state.ts`'s rendered footer.
- The help file itself passes `validate.mjs` + `verify_payload` in CI fashion (run at build time in this task; the PostToolUse hook guards later edits).
- Manual acceptance: fresh DMG install → ⌘? opens a zoomable help doc; remove its layers, press ⌘? again → pristine zoomable copy returns.
