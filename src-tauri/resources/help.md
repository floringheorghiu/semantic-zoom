# Semantic Zoom Help

Welcome! This document is the app's manual — and it is also a live demo. It carries its own zoom layers, so everything described below can be tried right here, on this very file. Drag the zoom control at the bottom of the window, or press `⌘2`, and watch this manual condense itself.

## What Semantic Zoom does

Semantic Zoom shows a markdown document at three depths of detail. The **Detail** level (`⌘1`) is the full original text. The **Sections** level (`⌘2`) replaces each section with a short conceptual summary — the gist without the jargon. The **Story** level (`⌘3`) condenses the whole document into a narrative: what was accomplished, what stands in the way, what happens next.

Documents written or updated by AI agents can grow long and repetitive. The zoom levels exist so you can find your bearings in seconds at the Story level, locate the section you care about at the Sections level, and drop into the full text only where it matters.

## Opening documents

Press `⌘O`, use File → Open…, or choose a recent file from the start screen. Semantic Zoom reads plain markdown (`.md` or `.markdown`) files.

A document opens in one of three states. If it carries zoom layers, all three levels are available immediately. If it is plain markdown, you'll see the full text and a **Generate summary** button for creating layers. If its embedded layers are damaged, the app shows the raw text with a warning and leaves your file untouched.

The app watches open files for changes. When an editor, an agent, or any other program saves the file, the view refreshes by itself within a moment — your reading position and text cursor are preserved wherever possible, and a brief "Updated" pill confirms the reload.

## Moving around

The zoom control at the bottom of the window switches levels by clicking or dragging. From the keyboard, `⌘1`, `⌘2`, and `⌘3` jump straight to a level, and the plain `[` and `]` keys step one level out or in. `⌘↓` and `⌘↑` move to the next or previous item at the current level, and `⌘⇧↓` / `⌘⇧↑` jump to the end or top of the document.

The map sidebar on the right mirrors the document's shape; clicking any bar scrolls to that part. `⌘+` and `⌘−` make the text larger or smaller, and `⌘0` restores the standard size. These size controls are independent of the semantic zoom levels.

## Generating zoom layers

For a plain markdown file, the **Generate summary** button asks a language model to write the section summaries and the story level, then stores them invisibly inside the file itself — as a comment block after your text. Your own words are never modified, and any other markdown app simply ignores the block.

Clicking Generate first asks where the generation should run: on your own machine, or through a remote provider. Local generation keeps the document on your Mac; remote generation sends the document's text to the provider you chose — the button's tooltip always states exactly where the text would go before you commit.

While generation runs, the button becomes a progress indicator; hover it and click to cancel. When it finishes, the file gains its layers and all three zoom levels unlock on the spot.

## Setting up a generation engine

Open Settings with `⌘,`. The Generation Engine panel has two choices to make: which kind of engine, and — for remote — which provider.

**Ollama (local).** Install Ollama, pull a model, and make sure it is running. The app talks to it at its standard local address. Nothing ever leaves your Mac.

**Custom local server (local).** For tools like llama.cpp's server or any OpenAI-compatible endpoint running on your machine: enter its base URL and the model name.

**Remote provider.** Pick a provider, enter its base URL and model if they differ from the defaults, and save your API key. The key is stored in the macOS Keychain — not in any file — and each provider has its own slot.

**About the Keychain.** The first time the app needs your API key, macOS asks whether to allow Keychain access. If you deny it, the app has to assume no key exists, and the Generate button will quietly disappear for remote providers. If Generate seems to be missing, this is the first thing to check: open Settings and confirm the key is present, then allow the Keychain prompt next time it appears.

## The status pill and the history card

The pill in the top-right corner always states what kind of document you're reading: **Native** for a file with zoom layers, **Untagged** for plain markdown, and a warning state if the embedded layers are damaged. Brief toasts appear on the pill when something happens — a reload, a finished generation, an error.

Hover the pill (or focus it with the keyboard) to open the history card. It lists every generation recorded for this document — the engine and model used, duration, tokens, temperature, version, and the full error text for failed attempts. The history lives in the app's own records, not inside your file, so sharing the document never shares its history.

## Removing zoom layers

The history card's top row is **Remove zoom layers…**. It deletes the generated layers from the file and returns it to plain markdown — byte for byte as it was before generation. A confirmation dialog explains what will happen before anything is touched.

Removal never erases history: past generations stay in the card, and the removal itself is recorded there too. Generation and removal are a loop you can walk in either direction — this very file is a good place to try it, because the next section explains how to get a fresh copy.

## About this help file

What you are reading is a copy, freshly made each time you open Help with `⌘?` or the Help menu. Experiment on it freely: zoom it, remove its layers, generate new ones with your own engine, edit it in another program and watch the live reload. Whenever you want the original back, press `⌘?` again and a pristine copy replaces this one.

## Keyboard shortcuts

- `⌘O` — open a document
- `⌘W` — close the document
- `⌘1` / `⌘2` / `⌘3` — Detail, Sections, Story level (plain `1`/`2`/`3` work too)
- `[` / `]` — step one level out / in
- `⌘↓` / `⌘↑` — next / previous item
- `⌘⇧↓` / `⌘⇧↑` — jump to end / top
- `⌘+` / `⌘−` / `⌘0` — text larger / smaller / standard
- `⌘,` — settings
- `⌘?` — this help file
